ABOUT

A QR generator with nothing to hide.

QRForge turns any text or link into a scannable QR code, right in your browser. There's no account, no server-side storage, and no tracking — your input is sent directly to a QR encoding API and rendered back as an image you can download or share.

It was built as a small, focused project: pick one job, do it cleanly, and make the interface itself feel like part of the experience — hence the scanner-bed layout and the laser sweep every time a code is generated.

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • QR Server API
  • Google Fonts
