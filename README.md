## 📖 Overview

**QRForge** is a modern QR code generator built with **HTML, CSS, and JavaScript**. It generates QR codes instantly in the browser with no backend or installation required.

## ✨ Features

- Instant QR generation
- 300×300, 500×500 and 800×800 output
- PNG download
- Copy input to clipboard
- Responsive dark UI
- Client-side only

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- QR Server API

## 🚀 Getting Started

```bash
git clone https://github.com/rattaneshguleria/qrforge.git
cd qrforge
```

Open `index.html` in your browser.
