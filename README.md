# 📖 Overview

**QRForge** is a modern QR code generator featuring a futuristic scanner-inspired UI. Built entirely with **HTML, CSS, and JavaScript**, it lets users generate high-resolution QR codes for text, URLs, notes, and more—without requiring any installation or backend server.

Everything runs directly in the browser using a public QR generation API.

---

# ✨ Features

- ⚡ Instant QR code generation
- 🔗 Supports URLs, text, notes, and custom data
- 📏 Multiple output resolutions
  - 300 × 300
  - 500 × 500
  - 800 × 800
- 📥 One-click PNG download
- 📋 Copy original input to clipboard
- 🌙 Modern dark-mode interface
- 📱 Fully responsive layout
- 🚀 No backend required

---

# ⚙️ How It Works

1. Enter any text or URL.
2. Choose the desired QR resolution.
3. Click **Generate Code**.
4. QRForge requests a QR image from the QR Server API.
5. The QR appears with a scanner-style animation.
6. Download the image or copy the original content.
